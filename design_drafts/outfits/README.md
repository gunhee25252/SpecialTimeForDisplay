# Outfit Drafts

These are unregistered 1024x1536 transparent PNG drafts for Photoshop alignment.
They are not referenced by the web application. The compact source renders are
preserved in `chroma_sources_compact/`.

The outfits were regenerated from existing outfit references with compact avatar
proportions. Measurements always use the visible alpha bounds and exclude the
transparent canvas. Existing groom outfits have width/height ratios of about
0.62-0.85. Existing compact bride outfits are about 0.62-0.91, while ball gowns
can be wider. New drafts were checked against those ranges instead of the full
1024x1536 canvas. Their neck edges begin around canvas y=641-644.
