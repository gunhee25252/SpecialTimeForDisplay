# Outfit Drafts

These are unregistered 1024x1536 transparent PNG drafts for Photoshop alignment.
They are not referenced by the web application. The compact source renders are
preserved in `chroma_sources_compact/`.

The outfits were regenerated from existing outfit references with compact avatar
proportions. Final placement uses uniform scaling only, so the source aspect ratio
is preserved. Groom outfits occupy about 422-472 x 585-610 px. Wide bride outfits
occupy 740-800 x 709 px, while compact bride outfits occupy 407-526 x 580 px.
Their neck edges begin around canvas y=641-644 to match the existing assets.

## Groom
