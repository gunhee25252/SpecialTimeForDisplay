# Accessory Sources

The files in `chroma_sources/` are the generated green-screen source renders.
Clean transparent versions used by the web app are in
`public/images/accessories/`.

The accessories are independent movable objects under the third decorating
step's `장신구` tab. They support move, scale, rotate, bring-to-front, and delete.

- single pearl drop earring (place twice for a pair)
- single gold hoop earring (place twice for a pair)
- crystal tiara
- floral hairpin
- pearl necklace
- black top hat
- ivory ribbon hat
- pink heart sunglasses
- black cat-eye sunglasses
- gold aviator sunglasses
- ivory oval sunglasses
- red slim sunglasses
- gold round sunglasses
- yellow star sunglasses
- rose-gold semi-rimless sunglasses
- the existing round glasses, moved from `오브제` to `장신구`
